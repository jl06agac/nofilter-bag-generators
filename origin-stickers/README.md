# Origin stickers — for the bag printing

Rescued 9 Sep 2026 from `_ARCHIVE/Clients-_shared-retired-2026-09-08/_design-refs/`, where it was the
only copy. Renamed from `-v3.html` to `-v2.html` because the file's own title and heading say v2;
there is no other version on the machine or in Drive.

- `NoFilter-origin-stickers-v2.html` — the sticker system: white NOFIL+ER mark centred, ring text
  = origin + NGO partner, placeholder colours distinct by hue and lightness so they read apart at
  sticker size. "Sized to sit over the bag's printed badge." References a `${MARK_URL}` template
  variable that has to be supplied when rendered.
- `badge-vectors/` — four ~1 KB placeholder badge outlines (triangle, hexagon, circle, ellipse),
  one per origin. NOT the origin illustrations; those are the 370 KB `Arakan-Mountains.svg` etc.
  on the CDN.

Related but not the same thing: `Brand/NF Upwork Files/Bags/nofilter-origin-stickers.png` in
